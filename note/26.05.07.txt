머신러닝 - 시스템이 *데이터를 통해 스스로 학습*하여 예측/판단/추론을 제공하는 기술

딥러닝 - 심층인공신경망 등의 *여러 비선형 변환기법의 조합*을 통해 높은 수준의 추상화를 시도하는 머신러닝



지도 학습 - 문제와 정답을 모두 알려주고 공부 - 분류

비지도 학습 - 답을 가르쳐주지 않고 공부 - 비슷한 애들끼리 모음 - 확률 분포

강화 학습 - 보상을 통해 상은 최대화, 벌은 최소화하는 방향으로 행위를 강화하는 학습


지도학습(Supervised Learning) - 레이블(정답)이 지정된 데이터를 사용하여 기계를 훈련시키는 방법
적용 사례 - 스팸 필터링, 이미지 분류, 의료 진단, 사기 탐지, 감정 분석 등
지도 학습의 활용
분류(classification) - 데이터 구분을 위한 기준(경계) 학습
회귀(regression) - 데이터 경향을 잘 표현할 수 있는 함수 학습

비지도학습(Unsupervised Learning) - 레이블이 지정되지 않은 데이터로부터 학습
적용 사례 - 구매 행동에 따른 그룹화, 구매 제품에 대한 연관 규칙 학습
비지도 학습의 활용
군집화(clustering) - 유사한 특징을 가지는 데이터끼리 군집화 -> 데이터의 고유한 구조/정보 학습
이상 탐지(anomaly detection) - 비정상적인 데이터 및 패턴 감지, 일반적인 패턴과 비일반적인 패턴 구분

강화 학습(Reinforcement learning) - 주어진 상황에서 목표에 도달하기 위한 행동을 학습

준지도 학습(Semi-supervised Learning) - 레이블이 있는 데이터와 레이블이 없는 데이터를 모두 학습에 이용
자기 지도 학습 (self-supervised learning)
- 레이블이 전혀 없는 데이터셋에서 레이블이 완전히 부여된 데이터셋을 생성
-> 레이블이 없는 이미지로 구성된 대량의 데이터셋이 있다면 각 이미지의 일부분을 랜덤하게 마스킹(masking)하고 모델이 원본 이미지를 복원하도록 훈련
-> 훈련하는동아 마스킹된 이미지는 모델의 입력으로 사용되고 원본 이미지는 레이블로 사용


학습 목적에 따른 머신 러닝의 유형
판별모델(Discriminate Model)
- 주어진 데이터의 확률을 모델링하여 레이블을 예측
- 입력 x에 대해 정확한 클래스 y를 예측
- 레이블의 차이를 적절하게 구분 짓는 결정 경계(Decision Boundary)학습
- 데이터의 분포를 잘 파악하고, 예측 정확도가 높음 | 새로운 데이터 샘플을 생성할 수 없음

생성모델(Generative Model)
- 데이터의 결합확률 p(데이터, 레이블)모델링하여 데이터의 분포 학습 이를 통해 p(레이블, 데이터)예측 가능
- 데이터의 생성 과정을 이해하고 새루운 샘플을 생성
- 데이터의 확률 분포 학습(주어진 데이터가 어떤 분포에 속할 확률이 높은지 결정하는 모델)
- 새로운 데이터 샘플 생성 가능 | 학습이 복잡하고, 예측 정확도가 낮을 수 있음

N-gram - 많이 썼는데 성능 개 구데기
Unigram (1-gram): 단어 하나만 고려합니다. 각 단어의 등장 확률은 전체 문서에서 해당 단어의 빈도로 계산됩니다.
Bigram (2-gram): 두 단어의 조합으로, 한 단어 다음에 다른 단어가 나타날 확률을 예측합니다.
Trigram (3-gram): 세 단어의 조합으로, 두 단어의 시퀀스 다음에 특정 단어가 나타날 확률을 모델링합니다.
N개의 단어를 연결해서 하나의 특징으로 사용
나는 오늘 수학 공부를 했다
나, 오늘, 수학, 공부

bi-gram
나-오늘
오늘-수학
수학-공부


워드 임베딩(Word Embedding) - 성능 좋음
단어를 문맥 기반으로 저차원의 밀집 벡터(dense vector)로 표현 - 벡터화
단어 간 의미적 유사성을 벡터화 하는 작업 -> 임베딩
단어의 의미를 여러 차원에 분산하여 표현 -> 분산 표현
임베딩으로 표현된 벡터 -> 임베딩 벡터


feature(특징)
feature set(특징 집합) - 단어 -> feature vector특징벡터
빈도수 -> count Vector -> 빈도수 벡터 -> 빈도수가 많으면 중요하게 인식한다
하지만 빈도수가 높다고 다 중요한것이 아님
-> TF-IDF Vector 사용(범용성이 높은 단어의 중요도를 낮춤)
TF:단어 빈도->중요할확률높음
IDF:역문서 빈도 -> 특정 단어가 얼마나 희소한지 나타냄, 
모든 문서에서 공통적으로 자주 등장하는 단어('그리고','의' 등)의 중요도를 낮우는 역할
공식:TF-IDF = TF X IDF
